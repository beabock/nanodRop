# nanodRop: Import Spectral Data Exported by 'NanoDrop One' Spectrophotometers

Reads the UV-Vis spectral text files exported by 'NanoDrop One'
spectrophotometers into tidy long-format tables with one row per sample,
measurement and wavelength, keeping repeated measurements and
timestamps. Also extracts absorbance differences or ratios at chosen
wavelength pairs, such as A260/A280.
